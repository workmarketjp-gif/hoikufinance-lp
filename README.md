# Hoiku Finance LP

Hoiku Finance の公式ランディングページです。

## コンセプト

**保育園の予算・会計・経営情報を、ひとつにつなぐ。**

法人本部を主対象に、園別予算管理、支出申請・承認、会計・決算、経営情報報告までを一つの流れで表現しています。

## 主なセクション

- Hero / 法人本部ダッシュボード
- 園別予算管理
- 支出申請・承認
- 会計・決算連携
- 経営情報報告
- ここdeサーチ向け確認・出力支援
- 複数園の予算・実績比較
- 日々の出納から決算までのフロー
- 料金 / CTA

## 実装

フレームワーク依存のない静的 HTML / CSS / JavaScript で構築しています。
Vercel ではそのままデプロイできます。
